#  Titanic Survival Analysis

##  Project Overview

The **Titanic Survival Analysis** project explores passenger data from the Titanic disaster using **Python, Pandas, NumPy, Matplotlib, and Seaborn**. The objective is to analyze the factors that influenced passenger survival and present meaningful insights through data visualization.

This project demonstrates the complete **Data Analysis workflow**, including data understanding, data cleaning, exploratory data analysis (EDA), visualization, and business insights.

---



#  Project Objective

The objectives of this project are to:

- Analyze passenger survival patterns.
- Compare survival rates by gender.
- Study survival across passenger classes.
- Analyze passenger distribution by embarkation port.
- Compare average fares by passenger class and gender.
- Examine survival rates across different age groups.
- Identify relationships between numerical features using correlation analysis.
- Generate meaningful business insights from the dataset.

#  Key Insights

- Approximately **48%** of passengers survived, while **52%** did not survive.
- Female passengers had a significantly higher survival rate than male passengers.
- First Class passengers were more likely to survive than Second and Third Class passengers.
- Southampton (S) was the busiest embarkation port.
- Higher ticket fares were generally associated with higher passenger classes and better survival rates.
- Survival varied across different age groups, indicating that age influenced survival outcomes.
- Correlation analysis showed that Passenger Class and Fare had stronger relationships with survival than other numerical features.
- The analysis suggests that **Sex, Passenger Class, Fare, Age, and Embarked** were the most influential factors affecting passenger survival.
